FedG2C 模块 A：从源图到共享参数的流程与代码对应

核对日期：2026-10-16。以下对应当前 `edge_prediction` 路径、`graphsage` 预测器和 `hypernetwork_relu` 组合器。说明基于当前源代码、配置和一次新运行的合成图单步追踪；没有修改模型实现。

**1．模块 A 在整个流程中做什么**

模块 A 是每个源客户端的本地自监督预训练：从允许使用的源图中截取局部图，对主分支输入遮边和遮蔽特征通道，经私有适配器、多个图专家和关系条件组合器产生节点表示；本地预测器用这些表示预测同一批节点在完整局部图上的动量参考表示。损失训练主分支和预测器，随后以 EMA 更新参考分支。训练完成后，仅将主分支的专家和组合器交给模块 B。

模块 B 聚合共享参数；模块 C 使用聚合后的共享基座开展目标域适应。A 中的预测器负责提供预训练任务，组合器属于希望保留和迁移的共享模型。

当前默认配置见 [fedg2c_edge_prediction.json](E:/UESTC/学业/实习/beihang_new/FedG2C/config/fedg2c_edge_prediction.json:2)。

| 符号或设置 | 当前默认值与含义 |
|---|---|
| `F` | 某个客户端的原始节点特征维数，由清单指定 |
| `N` | 一次局部视图的节点数，最多 32，不保证恰好 32 |
| `M` | 4 个独立参数的图专家 |
| `d` | 共享表示维数 64 |
| `H` | 组合器 4 个头，每头维数 `D=16` |
| `Q` | 本次预测节点数，随可见图变化；不是注意力中的查询张量 |
| `K` | RWSE 的 8 个返回概率通道，对应步数 1 至 8 |
| 邻域 | 参考视图取中心节点的 2 跳邻域；预测节点取可见图上的 1 跳邻域，均包含中心 |
| 输入扰动 | 按边组以 0.5 概率删除，按特征通道以 0.2 概率遮蔽 |
| 编码器 | 每个专家 2 层 `mysage`；默认预测器另有 1 层标准 PyG GraphSAGE |
| 更新 | AdamW：学习率 0.001、权重衰减 0.00001；EMA 系数 0.99 |

**3．输入如何变成 GraphView**

[data.py](E:/UESTC/学业/实习/beihang_new/FedG2C/fedg2c/data.py:9) 的 `read_manifest()` 读取客户端 ID、图文件路径和 `feature_schema`。图文件路径相对清单所在目录解析。`iter_graphs()` 从 CPU 加载张量字典或字典列表，构造 [GraphView](E:/UESTC/学业/实习/beihang_new/FedG2C/fedg2c/context.py:8)：

| 字段 | 形状 | 用途 |
|---|---|---|
| `x` | `[N_source,F]` | 连续节点特征或整数类别编号 |
| `edge_index` | `[2,E_source]` | 有向边记录；无向图通常用两条反向记录表示一条边 |
| `edge_attr` | 可选 `[E_source,F_edge]` | 与边记录逐行对齐的属性 |
| `original_node_id` | `[N_source]` | 对齐、追踪原节点；缺省为行号，不作为模型特征 |

加载器不传入 `y`、数据划分掩码、因素标签或预计算位置编码。允许哪些图进入清单，需要在准备数据时完成；加载器本身不执行组合留出、数据下载或自动审计。

`max_nodes=32` 限制的是单次模型视图。源图张量仍需要能够加载到内存，采样器也会建立源图邻接缓存。

**4．客户端内包含哪些模型、哪些参数**

[edge_client.py](E:/UESTC/学业/实习/beihang_new/FedG2C/fedg2c/edge_client.py:10) 深拷贝共同共享基座，再创建 `NodewisePredictionModel`。[edge_model.py](E:/UESTC/学业/实习/beihang_new/FedG2C/fedg2c/edge_model.py:44) 构造以下对象：

| 对象 | 组成 | 如何更新 | 是否上传 |
|---|---|---|---|
| `main_branch.node_adapter` | 节点私有输入适配器 | 本地 AdamW | 否 |
| `main_branch.edge_adapter` | 可选边私有输入适配器 | 本地 AdamW | 否 |
| `main_branch.shared.experts` | `M` 个图编码器 | 本地 AdamW，轮次间接收服务器状态 | 是 |
| `main_branch.shared.composer` | 关系条件组合器 | 本地 AdamW，轮次间接收服务器状态 | 是 |
| `predictor` | 表示投影、可选 RWSE 投影、GraphSAGE、输出层 | 本地 AdamW | 否 |
| `momentum_branch` | 整个主编码分支的副本，含适配器、专家、组合器 | EMA；下发后重新同步 | 否 |

`momentum_branch` 从创建时就 `requires_grad_(False)`，并保持 `eval()`；参考分支不包含预测器副本。

把适配器参数记为 `φ`，共享专家与组合器记为 `θ`，预测器记为 `ψ`，则本地梯度训练的是 `(φ,θ,ψ)`，参考分支对应 `(φ̄,θ̄)`，服务器只收 `θ`。

**5．一次本地训练怎样循环**

核心循环在 [EdgePredictionClient.pretrain](E:/UESTC/学业/实习/beihang_new/FedG2C/fedg2c/edge_client.py:35)：

```python
generator = torch.Generator().manual_seed(seed)
optimizer = AdamW(所有 requires_grad=True 的参数)
for epoch in range(epochs):
    for graph in graphs_factory():
        sampler = NeighborhoodEdgeSampler(graph)
        for _ in range(views_per_graph):
            pair = sampler.sample_edge_view(...).to(device)
            optimizer.zero_grad(...)
            loss, outputs = model(pair)
            loss.backward()
            clip_grad_norm_(..., max_norm=5.0)
            optimizer.step()
            model.update_momentum()
```

这是便于理解的伪代码；精确实现还检查损失和梯度是否有限，并记录统计量。一次采样视图对应一次优化步骤，没有在这里组装多个图的 minibatch。图按清单及文件内顺序遍历；每次采样重新选择中心、边掩码和特征掩码。`max_steps` 可提前结束一次本地训练调用。

**6．采样：先裁剪，再遮边，再选择预测节点**

[NeighborhoodEdgeSampler.sample_edge_view](E:/UESTC/学业/实习/beihang_new/FedG2C/fedg2c/edge_views.py:80) 的真实执行顺序如下。

第一步，选择具有非自环邻居的中心节点 `root`。没有这种节点的源图会报错。随后 `neighborhood()` 从中心逐跳扩展，默认最多 2 跳、32 个节点；容量不足时随机截断当前层，不从其他连通分量补齐。区域选择将邻接关系视为无向，实际子图保留输入边方向。

第二步，[induced_view](E:/UESTC/学业/实习/beihang_new/FedG2C/fedg2c/context.py:55) 用 PyG `subgraph(..., relabel_nodes=True)` 产生参考局部图：

```python
reference_view = GraphView(x_local, edges_local, attrs_local, original_ids_local)
```

它包含所选节点之间的原始局部边，不包含裁剪之外的节点及边。这里的“完整”始终指遮蔽前的局部图。

第三步，[mask_edges](E:/UESTC/学业/实习/beihang_new/FedG2C/fedg2c/edge_views.py:29) 随机删边。无向输入要求原始数据已有反向记录，以无序节点对分组，正反向及重复记录一起保留或删除；有向模式按有序节点对分组。对应 `edge_attr` 用同一个掩码筛选。

删除率是逐组伯努利概率，不是每次精确删除一半。小视图可以偶然一条边未删或全部删除，代码没有为此重采样。统计中的 `removed_edge_arcs` 计边记录数，因此一条无向边通常计两条。

第四步，构造可见局部图：

```python
visible_view = GraphView(reference.x, remaining_edges, remaining_attrs,
                         reference.original_node_id)
```

两分支保持相同节点、相同顺序和相同原始特征；此时区别是边和边属性子集。主分支的特征扰动在编码时施加，不直接改写 `visible_view.x` 或源图。

第五步，根据遮边后的可见边重新建邻接表，取中心默认 1 跳邻域作为 `prediction_indices`，包含中心。中心被遮成孤立节点时，预测集合仍至少包含中心。预测节点保留在主分支输入中，任务隐藏的是部分边和特征通道。

第六步，[sample_feature_keep](E:/UESTC/学业/实习/beihang_new/FedG2C/fedg2c/edge_views.py:51) 产生一维布尔通道掩码；所有节点共用它。最终输出：

```python
EdgePredictionPair(reference_view, visible_view, prediction_indices,
                   feature_keep, root_index, removed_edges)
```

`prediction_indices` 是局部行号；`root_index` 用于描述采样中心，后续模型不单独把中心编号输入网络。

**7．主分支：特征扰动与私有适配**

[NodewisePredictionModel.forward](E:/UESTC/学业/实习/beihang_new/FedG2C/fedg2c/edge_model.py:81) 首先校验两视图原始节点编号及顺序相同、预测索引合法，然后执行：

```python
main_z = self.main_branch(pair.visible_view, pair.feature_keep)
```

[MaskedEncodingBranch.forward](E:/UESTC/学业/实习/beihang_new/FedG2C/fedg2c/edge_model.py:18) 根据特征类型决定遮蔽位置。

连续特征：在原始 `F` 个通道中遮蔽，再用私有线性层投影：

`[N,F] → X ⊙ keep[None,:] → Linear(F,d) → [N,d]`。

类别特征：每列按 `node_cardinalities` 查独立嵌入表，所有列的嵌入相加，再遮蔽 `d` 个隐藏通道：

`[N,F] 整数编号 → Σ_j Embedding_j(x[:,j]) → [N,d] → 通道遮蔽`。

类别编号 0 可能是正常类别，所以不能用清零类别编号表达“缺失”。通道遮蔽也没有标准 dropout 的保留概率缩放。

可选边属性通过私有边适配器映射为 `[E_visible,d]`。当前不会另做边属性通道遮蔽；配置声明和实际边属性不一致会报错。有边属性时要求 `backbone=mysage`。

这些适配器允许不同客户端拥有不同的 `F` 或类别词表，同时共享统一的 `d` 维专家与组合器。

**8．M 个专家怎样得到 [N,M,d]**

[SharedBackbone](E:/UESTC/学业/实习/beihang_new/FedG2C/fedg2c/model.py:56) 构造 `M` 个独立参数的 `EdgePassingGraphEncoder`。每个专家读取同一份适配后特征和可见边，输出 `[N,d]`：

```python
h = torch.stack([expert(x, edge_index, edge_attr)
                 for expert in self.experts], dim=1)
# h: [N,M,d]
```

[EdgePassingGraphEncoder.encode](E:/UESTC/学业/实习/beihang_new/FedG2C/fedg2c/model.py:44) 逐层执行卷积和 LayerNorm，除最后一层外再执行 ReLU、dropout。该子类复用 Gefra `GraphEncoder`，并补上向 `EdgeAwareSAGEConv` 传递边属性的调用。

[EdgeAwareSAGEConv.message](E:/UESTC/学业/实习/beihang_new/FedG2C/model/graph_encoders.py:79) 对可见边 `j→i` 产生 `ReLU(h_j + e_ji)`；没有边属性时为 `ReLU(h_j)`。邻居消息做均值聚合、线性变换，并加上线性自身项，再交给编码器的归一化等操作。

当前专家都使用相同的欧式网络结构，但权重独立；没有预先给每个专家指定某种语义因素，也没有直接保证专家必然分工的损失。

**9．关系条件组合器怎样把 [N,M,d] 变成 [N,d]**

专家之后，[SharedBackbone.forward](E:/UESTC/学业/实习/beihang_new/FedG2C/fedg2c/model.py:73) 从当前分支自己的边构造关系，然后调用组合器。

[structural_relations](E:/UESTC/学业/实习/beihang_new/FedG2C/fedg2c/context.py:119) 返回 `[N,N,3]`：

`R = stack(I, A, 1[A @ A > 0])`。

三个通道分别是自身、直接有向边、两步可达。它们不是互斥的最短距离类别，两步可达可以与直接边重叠，也可以走回自身。主分支使用可见边；参考分支使用遮蔽前的局部边。关系编码不直接读取边类型、节点 ID 或 RWSE。

[RelationComposer.forward](E:/UESTC/学业/实习/beihang_new/FedG2C/fedg2c/composer.py:47) 将每个“节点×专家”位置视作一个 token。令 `L=N×M`：

| 操作 | 张量形状或公式 | 代码位置 |
|---|---|---|
| 展平、生成 Q/K/V | `[N,M,d] → [L,d] → 各 [L,H,D]` | 第 56 行 |
| 内容分数 | `einsum("qhd,khd->hqk", q/√D, k)`，输出 `[H,L,L]` | 第 60 行 |
| 关系偏置 | `[N,N,3] → [H,N,N] → [H,L,L]`，加到内容分数 | 第 61 行 |
| 按头归一化 | 固定 token 对，沿头轴做 RMS，得到 `code [H,L,L]` | 第 74 行、`head_rms()` |
| 第一次收缩 | `einsum("hqk,khd->qkd", code,v)`，沿头轴求和，输出 `[L,L,D]` | 第 22 行 |
| 非线性 | 上一步逐元素 ReLU | 第 24 行 |
| 第二次收缩 | `einsum("hqk,qkd->qhd", code,intermediate)`，沿 key 轴求和，输出 `[L,H,D]` | 第 25 行 |
| 输出 | 合并头、线性映射、残差、LayerNorm，再仅对专家轴平均 | 第 76 行 |

对每个查询 token `q` 和 key token `k`，第一次收缩把该 key 的各头 value 按 `code` 混成一个向量；第二次用同一份 `code` 把这些非线性中间向量汇入各查询头。其数学表达是：

`C_hqk = S_hqk / sqrt(mean_g(S_gqk²) + ε)`；

`U_qkt = ReLU(Σ_h C_hqk V_kht)`；

`O_qht = Σ_k C_hqk U_qkt`。

默认 `code` 可以为负，也不要求 key 轴求和为 1。普通 softmax 注意力对应可选 `standard_attention` 分支，不是默认两次收缩分支。

关系偏置是对交互分数的条件信息，不是只允许邻居交互的硬掩码。当前局部图内所有节点×专家 token 均可交互，包括遮边后处于不同连通分量的节点。因此不能把整个主编码分支的感受野只理解为专家的 2 跳可见邻居。

最后 `out.reshape(N,M,d).mean(dim=1)` 保留节点轴，输出 `[N,d]`。组合器没有把整张局部图池化为单个向量。默认路径会计算全部专家，并建立稠密 token 对分数，不执行 Top-K 专家选择；显式分数张量的大小随 `(N×M)²` 增长。普通 A 调用未额外传入 `relation_gate`。

与前次逐项解释对应的更细推导见 [组合器逐步解读](E:/UESTC/学业/实习/beihang_new/FedG2C/docs/FedG2C_组合器逐步解读_20261014.md)。

**10．RWSE 和默认 GraphSAGE 预测器做什么**

组合后的 `main_z [N,d]` 由本地预测器变成待比较的 `[Q,d]`。同一次 `forward()` 中，[random_walk_encoding](E:/UESTC/学业/实习/beihang_new/FedG2C/fedg2c/structural_encoding.py:12) 使用可见局部边，构造二值邻接矩阵 `A_visible`，按出度归一化得到转移矩阵 `T`，计算：

`RWSE_i = [(T¹)_ii, (T²)_ii, …, (T⁸)_ii]`。

这描述从节点出发若干步后返回自身的概率，形状为 `[N,8]`；孤立节点为零，不人为补自环。结构统计将重复边二值化，实际消息传递仍保留输入边记录。每次遮边后重新计算，没有读取完整源图的缓存位置编码。

[GraphSAGEPredictor.forward](E:/UESTC/学业/实习/beihang_new/FedG2C/fedg2c/graph_predictor.py:22) 执行：

```python
h = self.embedding(main_z)             # [N,64] → [N,predictor_dim]
h = h + self.position(visible_rwse)     # 可选：[N,8] → [N,predictor_dim]
prediction_all = self.output(
    self.activation(self.conv(h, visible_edge_index)))  # [N,64]
prediction = prediction_all[prediction_indices]         # [Q,64]
```

该预测器调用一层标准 PyG `SAGEConv`：可见邻居做均值聚合，保留自身项，随后 ReLU 和输出层。它不接收完整参考边或边属性。自身项允许孤立节点继续获得预测输出。

RWSE 作为预测器的结构条件，位于组合器之后；组合器的三通道关系偏置位于编码过程，两者用途不同。`position_encoding=none` 时预测器不加结构投影；当前 `edge_model.py` 仍调用 RWSE 计算，结果不参与该预测器的输出。

`predictor_depth=2`、`predictor_heads=4` 只影响可选 Transformer 预测器，默认 GraphSAGE 固定一层。若选择 `transformer`，[NodeRepresentationPredictor.forward](E:/UESTC/学业/实习/beihang_new/FedG2C/fedg2c/node_predictor.py:31) 将投影后的上下文节点序列与 `mask_token + position[q]` 查询序列拼接，经 Transformer 后读取查询部分；这是单独保留的对照路线。

**11．参考分支怎样提供目标，损失怎样计算**

[edge_model.py](E:/UESTC/学业/实习/beihang_new/FedG2C/fedg2c/edge_model.py:100) 在 `torch.no_grad()` 中执行：

```python
reference_z = self.momentum_branch(pair.reference_view)  # [N,d]
reference = F.layer_norm(reference_z, (d,))[q]            # [Q,d]
loss = F.smooth_l1_loss(prediction, reference)
```

参考分支不接收 `feature_keep`，使用遮蔽前的局部节点特征、边和可选边属性，经动量适配器、动量专家和动量组合器编码。然后逐节点沿特征维做 LayerNorm，再使用同一组局部索引 `q` 选取目标。这不是节点维度池化，也不是 L2 单位长度归一化。

可写为：

`Z_main = f_{φ,θ}(G_visible, feature_keep)`；

`Y_hat = P_ψ(Z_main, RWSE_visible, E_visible)[q]`；

`Y_ref = stopgrad(LayerNorm(f_{φ̄,θ̄}(G_reference))[q])`；

`L = SmoothL1(Y_hat, Y_ref)`。

默认 Smooth L1 对 `Q×d` 个标量取均值，`β=1`；误差小于 1 时为 `0.5×error²`，较大时为 `|error|-0.5`。它是连续潜表示回归，没有边分类标签、负边采样或下游分类头。

函数返回的 `outputs["prediction"]` 和 `outputs["reference"]` 为 detached 诊断数据；损失在 detach 之前计算，仍保留主分支和预测器的梯度。

**12．梯度更新与 EMA 的先后关系**

[edge_client.py](E:/UESTC/学业/实习/beihang_new/FedG2C/fedg2c/edge_client.py:48) 先反向传播、将所有可训练参数梯度范数裁剪到最多 5，再执行 AdamW；之后才调用 [update_momentum](E:/UESTC/学业/实习/beihang_new/FedG2C/fedg2c/edge_model.py:73)：

`φ̄_{t+1} = μφ̄_t + (1-μ)φ_{t+1}`；

`θ̄_{t+1} = μθ̄_t + (1-μ)θ_{t+1}`。

当前 `μ=0.99`，不做动量调度。EMA 包含主分支的私有适配器及共享专家、组合器，不包含 `predictor`；buffer 直接复制。当前步参考目标使用更新前的动量分支，EMA 更新后的状态用于后续步骤。

梯度从预测损失经过预测器、组合器、各专家回到私有适配器；参考分支只提供停止梯度目标。该设计意图是用变化更慢的参考表示形成稳定预测任务，实际是否避免塌缩和提升泛化仍需测量。

`context_std`、最近最多 128 个参考节点的 `reference_std` 是诊断统计，不是额外损失，也不是非塌缩保证。

**13．一轮结束交给 B 什么，下一轮保留什么**

[get_pretrain_model](E:/UESTC/学业/实习/beihang_new/FedG2C/fedg2c/edge_client.py:25) 仅导出 `main_branch.shared.state_dict()` 的 detached CPU 克隆，键名以 `experts.` 或 `composer.` 开头。[get_local_message](E:/UESTC/学业/实习/beihang_new/FedG2C/fedg2c/edge_client.py:29) 进一步封装为 [Gefra 风格消息](E:/UESTC/学业/实习/beihang_new/FedG2C/fedg2c/messages.py:35)：

```python
{"num_samples": 1,
 "weight": [("experts.…", tensor), ("composer.…", tensor), ...]}
```

`num_samples=1` 是当前接口兼容字段，不代表真实客户端图数或节点数。数据、适配器、预测器、RWSE 投影、EMA 副本和本地诊断统计不进入该消息。

下一轮 [set_pretrain_model](E:/UESTC/学业/实习/beihang_new/FedG2C/fedg2c/edge_client.py:16) 只覆盖主分支共享状态，再调用 `reset_momentum()` 将整个当前主编码分支复制到参考分支。

| 状态 | 联邦轮次之间的行为 |
|---|---|
| 主分支共享专家与组合器 | 接收本轮服务器下发状态 |
| 主分支私有节点/边适配器 | 保留前轮本地参数 |
| 本地预测器及其 RWSE 投影 | 保留前轮本地参数 |
| EMA 分支 | 下发后重新与整个当前主编码分支同步 |
| AdamW 状态 | 每次 `pretrain()` 新建，动量等优化器状态不跨调用保留 |

单独 A 入口保存 `shared_backbone.pt`、`local_training_state.pt` 和 `metrics.json`；联邦入口另保存本地私有模型快照。这些保存模型权重及元数据，没有保存精确恢复所需的完整优化器和 RNG 状态。

**15．这些步骤参考了什么，为什么参考**

下表的来源关系依据当前文件头说明和项目已有溯源文档；本次没有新增对外部仓库的同权重复现验证。

| 来源 | 对应本实现 | 参考目的与范围 |
|---|---|---|
| Gefra | 图编码器、欧式多专家结构、客户端 set/pretrain/get 边界、命名参数消息 | 复用已有图学习和联邦训练接口；当前新路径不继承其几何专家或稀疏 Top-K 路由 |
| I-JEPA | 潜表示预测、停止梯度参考、逐节点目标归一化、Smooth L1、EMA | 提供不依赖标签的预测信号；独立图适配，默认预测器是 GraphSAGE，输入扰动方式也有差异 |
| BGRL | 随机删边、全体节点共用的特征通道掩码 | 构造图输入扰动；本项目增加有界局部视图、无向边分组和类别安全遮蔽，没有采用其完整双向视图目标 |
| Attention as a Hypernetwork / HYLA | 头轴 RMS、复用条件编码的两次张量收缩及中间 ReLU | 提供已有的条件非线性组合核心；图关系偏置和节点×专家布局是本项目适配 |
| GraphGPS | 随机游走返回概率 RWSE | 为预测器提供可见图结构条件；只迁移该计算，不采用整套 GraphGPS 模型 |
| GraphSAGE / PyG | 默认预测器中的一层 `SAGEConv` | 直接使用可见邻居和自身项生成逐节点输出；调用库实现 |
| GraphMAE | 浅层图解码器的设计参考 | 给预测器引入浅层图聚合的参考；当前目标是动量潜表示，没有迁移 GraphMAE 的原特征重构目标 |
