# FedG2C 详细介绍：设计动机、模型、训练流程与代码溯源

核对日期：2026-10-10。对象是当前 `FedG2C/` 目录的新设计路径；源码参照是用户指定的 `FedGFM2oE-baselines-merged/` 当前工作树。本文结合根目录四份说明、实际入口、`fedg2c/` 实现、保留的 Gefra 实现、固定提交的第三方代码及本次合成运行产物。没有修改原模型代码或原说明文件。

**核心结论：FedG2C 将研究重点放在“图关系条件下的专家组合能力”上：客户端用逐节点联合嵌入预测学习专家与组合器，服务器用合成图上的输出与关系响应校准聚合权重，目标域冻结共享基座并训练少量适应参数。** 三阶段代码已连接；真实数据上的组合泛化收益仍是待检验的研究假设。

文中“实现事实”来自当前代码；“设计解释”说明这些机制为什么可能有用；“教学例子”帮助理解，不表示专家已经学到了对应语义；“实验建议”是尚未执行的正式验证方案。

## 1. 背景：为什么联邦图基础模型还要研究“组合”

图基础模型希望从多个源图学习可迁移的表示，供后续节点分类、图分类等任务使用。联邦环境把源数据保留在不同客户端，各客户端在本地训练，服务器汇总共享参数。这种设定有两个直接困难。

第一，图域之间的输入与结构差异很大。例如，文献图可能具有连续文本特征，分子图具有离散原子／键类别；社区结构、度分布、局部环路和节点之间的依赖也可能不同。统一原始特征并不自然。FedG2C 用私有输入适配器把各域映射到同一个隐藏维度，再在这一空间共享专家与组合器。

第二，训练中见过若干结构或因素，并不代表模型能处理它们的新组合。**领域偏移**关注换了数据域以后是否可用；**组合偏移**更具体：组成部分可能分别见过，但它们共同出现的方式没有见过。客户端之间的组合覆盖不一致，又会使聚合模型面临新的困难。

教学例子：用两个二元因素 a、b 描述某类图结构。源域包含 00、10、01，目标测试包含 11。这表示两个因素单独出现的情形已有来源，但同时出现的组合被留出。若源训练中连 a 本身也从未出现，问题就同时包含新因素与新组合，不能只称为纯组合泛化。

实际分子因素可以由预先定义的子结构或属性描述，非分子图也可以由结构模式描述。但是，**当前 FedG2C 模型并不接收这种因素标签，也没有自动生成 00／10／01／11 划分**。因素定义、源数据过滤、目标支持集与组合留出必须在数据准备阶段完成，不能由模型名字或预测损失代替。

## 2. 动机：分别解决“学会组合、聚合后保留、迁移时使用”

FedG2C 的三部分对应一条完整研究链。

| 阶段 | 要解决的具体问题 | 当前设计 | 预期收益及其证据边界 |
|---|---|---|---|
| A：本地关系条件专家组合学习 | 多专家是否只被简单加权，还是可以结合图关系发生交互？ | 欧式图专家＋关系条件超网络组合器；受扰动图预测完整局部图的节点潜表示 | 希望学到可迁移的结构组合规则；损失下降不能证明组合泛化 |
| B：服务器关系响应保持聚合 | 参数平均以后，组合器对关系变化的反应是否被破坏？ | 用随机图探针匹配基准读数与关系扰动响应，学习客户端聚合权重 | 希望减轻聚合造成的行为变化；合成探针匹配不能保证真实图上的保持 |
| C：目标域组合适配 | 学到的共享基座是否能在少量目标域训练下发挥作用？ | 冻结原专家与完整组合器，训练目标适配器、任务头及一种可选适应模块 | 检验不同任务、不同适配方式下的迁移；不把成熟适配方法分别当成新贡献 |

这三个问题不能互相替代。A 的本地表示有效，不代表 B 的聚合后仍有效；B 的探针误差小，不代表 C 的未见组合任务一定好。正式实验应沿着这条链分别提供证据。

设计上的另一个重点是把**组合器本身**设为共享知识。原 Gefra 当前代码的上传边界主要是专家与几何投影器，预训练门控保留在客户端；下游另建提示读出。FedG2C 上传完整 `composer.*`，包括关系映射，并在目标域加载同一个组合器的原参数。因此，“在源域学习如何组合，并把这套规则传给目标域”在新代码中有明确的参数载体。

## 3. 与 Gefra 的关系：继承了什么，改变了什么

原 Gefra 的路线围绕多曲率黎曼专家、几何投影、几何感知聚合和黎曼提示读出展开。FedG2C 保留原运行文件，新增独立路径研究图关系与专家组合。

| 维度 | 当前目录保留的 Gefra 路径 | FedG2C 新路径 |
|---|---|---|
| 专家 | 多曲率黎曼专家；另有欧式专家消融 | 同一欧式隐藏空间内的多个独立图编码器 |
| 专家融合 | 节点内门控、Top-K 专家选择后加权 | 节点×专家 token 的内容与关系条件交互；默认非线性两次收缩 |
| 几何模块 | 曲率、几何投影器等 | 新路径不使用这些几何模块 |
| 本地预训练 | 拓扑重构、局部／共享结构对齐及曲率多样性项等 | 遮边＋特征通道遮蔽后的逐节点动量潜表示预测 |
| 共享内容 | `moe_encoder.experts.*`、可选 `geo_projector.*` | `experts.*` 和完整 `composer.*` |
| 服务器 | GW 权重、专家排列对齐；另有固定平均消融 | 固定平均，或学习客户端参数凸组合权重；新路径没有排列对齐 |
| 下游 | 冻结专家／投影器，建立 Riemannian Prompt Readout 等 | 冻结专家与源域组合器，使用 LoRA／残差 Adapter／组合输入 Prompt 对照 |
| 数据入口 | 既有数据集配置、缓存、划分流程 | 显式源域／目标域张量清单 |
| 新任务范围 | 原路径含节点、关系／链路、图任务 | 新目标入口支持节点分类和图分类；没有新增链路预测微调入口 |

这里还要区分两种“关系”。Gefra 的 `model/expert_relations.py` 表示专家之间由参数距离和曲率距离构造的 M×M 关系，用于几何聚合。FedG2C 的 `r_uv` 是**节点对的图结构关系**，形状 N×N×3，作用于专家组合器。这两个概念不同。

源码内容比对中，忽略 BOM 和换行形式后，112 个纳入比较的原有／新增代码、配置和说明文件中，45 个与源工作树文本一致，8 个同名文件内容有差异，59 个只存在于 FedG2C。其中 `model/graph_encoders.py`、`model/experts.py`、`model/pretraining.py`、`flcore/client.py`、`flcore/server.py` 文本一致。新专家直接导入原图编码器，而不是导入会引入几何依赖的整个专家模块。

源目录当前 HEAD 为 `094e2b3465dd12dee82c2b09e18dd9551b59c00e`，还有未提交修改；当前 FedG2C 目录没有 Git 元数据。这只能证明核对时的内容关系，不能确定复制日期、修改先后，也不能把源目录后续的 PCBA–HIV 实验接点当作当前新路径已有能力。完整比较见 [source_comparison.json](review_artifacts_20261010/source_comparison.json)。

## 4. 模型的对象、形状与共享边界

设当前局部图有 N 个节点，客户端原始节点特征维度为 F，隐藏维度为 d，专家数为 M，组合头数为 H。

| 对象 | 形状／组成 | 是否共享 |
|---|---|---|
| 原始节点特征 X、边及可选边属性 | N×F、2×E、E×F_edge | 留在客户端；不输入服务器聚合函数 |
| 私有节点／边适配器 | 连续输入线性投影，或逐列类别嵌入求和 | 不共享 |
| M 个欧式专家 | 每个专家输出 N×d；合并为 N×M×d | 共享 |
| 图关系 R | N×N×3；由当前可见边计算 | 每次本地计算；不是需要上传的源图摘要 |
| 关系条件组合器 C | Q／K／V、关系映射、输出映射、归一化；输出 N×d | 完整共享 |
| GraphSAGE 预测器及结构位置投影 | N×d → 预测位置上的 Q_count×d | 不共享 |
| EMA 参考编码分支 | 主编码分支的动量副本，含私有适配器与共享结构 | 不共享；不含预测器 |
| 目标域适配器与任务头 | 按目标特征及类别维度新建 | 目标域本地训练 |

共享基座可写为 θ={E_1,…,E_M,C}。客户端 k 的本地完整训练模型还包含私有参数 φ_k、预测器 ψ_k 和参考副本。目标域只加载 θ，不加载任何源客户端的 φ_k、ψ_k 或参考分支。

当前默认共享结构为 d=64、M=4、H=4、每专家两层 `mysage`、LayerNorm、Dropout=0。其共享状态含 83,852 个参数、51 个张量键；float32 张量有效载荷为 335,408 字节。这是当前配置的规模，不代表全部配置或所有方法的通信规模。

## 5. A：客户端怎样学到表示与组合规则

### 5.1 先取有界局部图，再制造受扰动视图

`NeighborhoodEdgeSampler.sample_edge_view` 先在有非自环邻居的节点中选一个中心，取默认 2 跳、最多 32 个节点的邻域，并得到诱导子图。超出上限时在当前层随机取部分节点，不用其他连通分量填满节点数。

随后生成两个保留**相同节点与顺序**的视图：完整局部图供参考分支使用；可见图供主分支使用，随机删除边并遮蔽特征通道。默认遮边率 0.5、通道遮蔽率 0.2。

无向模式以无序节点对为单位删除边，反向边和重复边一起保留或删除，边属性同步过滤。它不补造原数据中缺失的反向边；声明无向输入但没有对应反向边会报错。有向模式保留方向。

特征遮蔽是一份对全部节点共享的通道掩码。连续输入在私有线性投影之前遮蔽原始 F 个通道；类别输入先按列嵌入并求和，再遮蔽 d 个隐藏通道。这样避免把合法的原子／键类别 0 错当作缺失值。当前没有额外的边属性通道遮蔽。

预测位置根据**可见图**上的中心节点邻域选择，默认 1 跳并包含中心节点；遮边后中心可能孤立，仍可预测中心自身。完整参考视图仅指遮蔽前的这个局部子图，不是整张源图。

### 5.2 私有适配器统一输入，专家产生多个表示视角

连续节点特征映射为：

$$
\widetilde X_k=X_kW_k+b_k\in\mathbb R^{N\times d}.
$$
离散输入根据显式声明的每列类别数量建立 Embedding，然后把各列嵌入相加。边属性也可以经私有适配器映射到 d 维。不同域的原始维度和词表可以不同，但共享专家的输入／输出形状一致。

每个专家独立运行图编码：

$$
H_{v,m}=E_m(\widetilde X,\widetilde A,\widetilde E)_v,
\qquad H\in\mathbb R^{N\times M\times d}.

$$
默认 `mysage` 的邻居消息含 `ReLU(x_j+e_ji)`，无边属性时为 `ReLU(x_j)`，随后均值聚合、线性映射并加入根节点映射。`EdgePassingGraphEncoder` 继承原 `GraphEncoder`，覆盖编码调用，把边属性送入其支持的 `EdgeAwareSAGEConv`；原 `GraphEncoder.encode` 本身没有转发边属性。新增封装没有改写原文件。

**专家是多个可学习视角，不是预先标注的语义因素。** 当前没有专家身份嵌入、显式因素监督、强制语义分工或专门的专家多样性损失。可以用“某些专家可能偏向某类模式”解释动机，但不能断言专家 1 已负责官能团 a、专家 2 已负责 b。

### 5.3 关系条件组合器究竟组合什么

当前关系描述由可见邻接矩阵 A 构造：

$$
r_{uv}=\left[\mathbf1(u=v),\ A_{uv},\ \mathbf1((A^2)_{uv}>0)\right].
$$
三个通道分别是自身关系、直接边、存在两步路径。它们不是互斥类别；两个节点可以同时具有直接边和两跳关系，无向图的两跳关系也可能在对角线上非零。它们是通用拓扑描述，不是原子键类型、任务标签或组合因素。

组合器把 H 展开成 NM 个 token，一个 token 表示“某个节点在某个专家下的表示”。对 token t=(u,m)、s=(v,n)，第 h 头分数为：

$$
S^{(h)}_{ts}=\frac{\langle W_QH_{u,m},W_KH_{v,n}\rangle}{\sqrt{d/H}}
+b_h(r_{uv}).

$$
关系映射 `Linear(3,H,bias=False)` 给每个头产生一个图关系偏置；同一节点对的偏置重复到全部专家对。因此组合同时考虑 token 内容和节点关系，包含跨节点、跨专家交互。当前局部视图使用全交互掩码：即使某节点对三个关系通道都为零，内容相似度项仍可产生交互，不是只在两跳邻居之间硬性路由。

默认超网络模式不使用标准的 key 轴 softmax，而是按**头轴**做 RMS 归一化：

$$
C^{(h)}_{ts}=\frac{S^{(h)}_{ts}}
{\sqrt{\frac1H\sum_{h'}(S^{(h')}_{ts})^2+\epsilon}}.
$$
这里 C 不是非负概率分布。随后复用同一条件编码进行两次收缩：

$$
U_{tsc}=\sum_h C^{(h)}_{ts}V_{shc},\qquad
O_{thc}=\sum_s C^{(h)}_{ts}\operatorname{ReLU}(U_{tsc}).
$$
这来自 Attention as a Hypernetwork 的多头条件编码／两次收缩核心：条件编码参与一次值变换，再在非线性之后参与一次组合。相比简单专家加权，它提供了输入条件下更丰富的交互。

最后，每个 token 经输出投影、残差和 LayerNorm，同一节点的 M 个专家 token 再求均值：

$$
z_u=\frac1M\sum_m\operatorname{LN}(H_{u,m}+W_OO_{u,m})\in\mathbb R^d.
$$
**只平均专家轴，不平均节点轴。** 输出仍然是 N×d 的逐节点表示。图任务等到下游读出时才进行图池化。

直觉上，模型不只回答“这个节点选哪些专家”，还可以根据“这个节点与另一个节点相邻、两跳相连或自身对应”，调整多个表示视角如何影响彼此。这是组合能力的候选实现；是否与真实语义组合相符需要分析和消融。

组合器提供 `hypernetwork_relu`、去 ReLU 的 `hypernetwork_linear`、`standard_attention` 和节点内 `linear_gate` 对照。线性门控不含关系分支。默认没有稀疏 Top-K；所有专家都编码。虽然文档沿用“超网络线性注意力”名称，当前显式存储 NM×NM 两两分数，不能宣称节点规模上的线性复杂度。节点上限和专家数量直接影响内存与计算。

### 5.4 为什么还需要结构编码和 GraphSAGE 预测器

主分支的表示 z 输入本地预测器。随机游走结构编码只使用可见边：对出度归一化转移矩阵 T，提取

$$
\operatorname{RWSE}(v)=\big[(T^1)_{vv},\ldots,(T^8)_{vv}\big].
$$
返回概率让预测器获得节点在可见局部图中的结构描述。重复边视为一个结构边，孤立节点的转移行和返回概率按零处理。这里没有来自完整参考图的预计算位置编码，也不把原节点 ID 当作网络输入。

默认预测器是一层标准 PyG `SAGEConv`：
$$
\widehat z=P_\psi(z,\operatorname{RWSE},\widetilde A).
$$
实际结构是输入线性映射＋可选 RWSE 线性映射，一层含根节点项的 GraphSAGE、ReLU、输出线性映射，然后取预测索引。它利用可见邻域的主表示，根节点项也能处理遮边后孤立的位置。`predictor_depth` 和 `predictor_heads` 只用于保留的 Transformer 对照；不能把 JSON 中 `predictor_depth=2` 解读为默认有两层 GraphSAGE。

`edge_prediction` 的准确任务是**边／特征扰动下的节点潜表示预测**：预测节点仍保留在可见输入中，特征受通道遮蔽；输出不是边概率，没有负边采样，也没有重构邻接矩阵的二分类损失。这与原 Gefra 拓扑重构、MaskGAE 结构重构以及旧版移除目标区域的预测都不同。

### 5.5 动量参考、损失和本地更新

参考分支是整个主编码分支的副本，包括私有输入适配器、专家和组合器，但不包括预测器。它读取未遮边、未遮特征的完整局部图，输出逐节点表示并在每个节点的特征轴上 LayerNorm，取相同预测索引，停止梯度：

$$
y_v=\operatorname{stopgrad}\left(\operatorname{LN}
\left[f_{\bar\theta,\bar\phi}(G_{local})_v\right]\right),\qquad
\mathcal L_A=\operatorname{SmoothL1}(\widehat z_{\mathcal Q},y_{\mathcal Q}).
$$
主分支、私有适配器和预测器由 AdamW 更新，梯度范数裁剪阈值为 5。优化之后，用固定动量 m=0.99 更新参考编码参数：

$$
\bar\Theta\leftarrow m\bar\Theta+(1-m)\Theta.
$$
参考分支处于评估模式，不由损失直接更新。每轮收到新共享基座后，把参考分支重置为当前主分支；私有适配器和预测器保留在各客户端。每次 `pretrain` 调用重建优化器，所以当前不跨通信轮保留 AdamW 动量状态。

这种任务促使主分支从不完整结构和特征中恢复稳定潜表示，避免必须为异构原始输入定义统一重构目标。但 EMA、停止梯度和 LayerNorm 都不构成非坍塌证明；当前最后至多 128 个参考节点的标准差只是诊断。结构捷径、特征捷径及专家冗余也仍需对照实验。

## 6. B：服务器为什么比较“输出”和“响应”

### 6.1 从参数相近转向功能上的可检验约束

不同客户端在不同图分布上更新专家与组合器。即使采用同一初始化，对参数做平均也不等于平均其功能，因为编码和组合是非线性的。聚合模型可能在某个输入上给出相近输出，却对关系偏置的小变化反应不同。

教学例子：两个模型在门控 g=1 时都输出 0.6，一个在 g 增大时读数上升，另一个几乎不变。只约束 g=1 的值无法区分这两者。FedG2C 因此同时约束值和局部变化率。这是从 GAD 的敏感性保持思想迁移过来的直觉，并不意味着 GAD 的图像实验已经验证了图关系组合。

### 6.2 服务器不需要同一个标签空间

服务器只接收 K 个客户端的共享状态。在标准高斯特征和随机块模型图上运行它们：

$$
X_{probe}\sim\mathcal N(0,I),\qquad A_{probe}\sim\operatorname{SBM}.
$$
高斯特征维度是 d，直接进入共享专家的输入空间，**绕过客户端私有适配器**。默认探针有两个各 8 节点的社区，块内概率 0.5，块间概率 0.1；每轮 4 个校准图、2 个独立诊断图。

探针不使用客户端真实图、特征统计、分类标签或语义因素，没有边属性，也不是分子生成器。这解决的是“服务器如何获得统一、可重复、无需真实图的功能测试输入”，没有证明随机高斯特征代表目标数据分布。

每个探针选默认 16 对无序、非自身节点对，读取组合节点表示的余弦相似度：

$$
s_{uv}=\frac{z_u^\top z_v}{\|z_u\|\|z_v\|}.
$$
它不是链路概率或任务 logits，因而不要求跨域类别空间一致。共同正交变换不改变这种读数，但余弦读数也不保留全部表示信息，不能据此解决参数或专家槽位的对齐问题。

### 6.3 “关系响应”准确扰动的是哪里

组合器关系项改为：

$$
b_h(r_{uv})\longrightarrow g_{uv}b_h(r_{uv}),\qquad g_{uv}=1.
$$
在至少一种关系非零的位置生成随机方向 δ；无向模式使它对称，用整个方向矩阵的 Frobenius 范数归一化到 1。默认每图两个方向，ε=0.01。响应为：

$$
R_\theta^{(j)}=
\frac{s_\theta(1+\epsilon\delta_j)-s_\theta(1-\epsilon\delta_j)}{2\epsilon}.
$$
对一份探针、一个候选模型，专家只编码一次；基准与正负扰动共享 H、图、特征和关系矩阵，**只扰动组合器关系偏置的乘法门控**。不会增删边，不重跑不同拓扑上的专家，不修改原子／键类别。因此该响应是沿关系门控方向的局部有限差分，不是对实际结构编辑的完整响应，更不是语义因素的因果效应。

参考侧是本轮上传模型的固定无梯度读数和响应；每轮重新缓存。每轮探针由固定种子规则生成，并保存实际探针张量。独立诊断图不参与聚合权重选择。

### 6.4 学的是客户端权重，不是一个自由学生网络

K 个 logits 经 softmax 得到客户端权重：

$$
w_i=\frac{e^{a_i}}{\sum_j e^{a_j}},\qquad
\theta(w)=\sum_iw_i\theta_i.
$$
同一组 K 个权重用于全部专家、组合器层和关系映射。没有逐层／逐专家聚合权重，也没有额外整体缩放。最终参数限制在上传模型的凸包内，而不是另训练任意参数的学生模型。

完整服务器目标是：

$$
\mathcal L_B=
\lambda_o\sum_i\rho_i\operatorname{MSE}(s_{\theta(w)},s_{\theta_i})+
\lambda_r\sum_i\rho_i\operatorname{MSE}(R_{\theta(w)},R_{\theta_i})+
\lambda_p\|w-p\|_2^2.
$$
MSE 在探针、测量对及方向上平均。默认 p_i=ρ_i=1/K，初始化 a_i=log p_i。p 是固定平均基线，ρ 是固定参考重要性；两者不随待学习 w 改变。否则模型可能通过降低难匹配客户端的“参考权重”绕开误差。

从这个平方目标还可以推导：固定参考之间的加权平方误差，等价于匹配它们的固定加权均值，再加一个与候选无关的参考分歧常数。因此它提供的是折中目标，不要求候选同时精确复制所有不同客户端。代码中的逐客户端诊断可以揭示某一客户端是否被牺牲。

用 `torch.func.functional_call` 在真正的加权参数上前向，保留 a→w→θ(w)→读数→损失的梯度。服务器只用 Adam 更新 K 个 logits；上传参数和参考读数都固定，模板模型处于评估模式。非参数缓冲区要求各客户端完全相同，不静默平均整数统计或运行缓冲。

默认更新 10 步、学习率 0.05，λ_o=λ_r=1、λ_p=0.001，采用最后一步权重。响应误差通常明显小于输出误差；同取系数 1 不表示贡献相等，当前没有自动归一化或自适应平衡。

### 6.5 三个聚合对照、通信与限制

| 模式 | 优化内容 | 用途 |
|---|---|---|
| `fedavg` | 固定均匀平均；没有探针与服务器优化 | 继承 Gefra 当前固定平均边界；不是按真实样本数加权的 FedAvg |
| `output_only` | 基准输出匹配＋权重偏离项 | 隔离可学习权重与零阶功能匹配的收益 |
| `response` | 基准输出＋关系响应匹配＋权重偏离项 | 检验响应项是否提供独立收益 |

`response` 要求有效关系分支。没有关系条件或使用 `linear_gate` 时应使用前两种模式，不能把零响应当成成功保持。`output_only` 的优化历史中 `response_mse=0` 是未计算该损失项的占位；真实响应诊断要读 before／after 字段。

运行消息沿用 Gefra 形状：下发命名张量列表，上传 `client_id → {num_samples:1, weight:[(name,tensor),…]}`。`num_samples=1` 是兼容字段，不是真实样本量；固定平均和默认参考权重都不从它推导。实际上传仅含 `experts.*` 和 `composer.*` 的 CPU 分离副本。

每轮一次共享下发与一次共享上传；服务器十步校准没有十次客户端往返。当前通信报告只计张量有效载荷，未计序列化、网络、重传和磁盘开销。新联邦入口是单进程、全客户端参与的仿真；未实现客户端抽样、掉线恢复或生产网络部署。

新路径也没有 Gefra 的专家排列匹配：相同初始化与槽位对应是参数混合的前提，而不是已被形式证明的保障。服务器保留全部上传模型及探针缓存，增加了内存和计算成本。模型参数未上传原图这一事实，也不等于差分隐私、抗反演或形式隐私保证。

## 7. C：冻结共享基座，怎样做目标域微调

### 7.1 加载原专家和原组合器，重新建立目标域接口

目标加载器只接受 B 输出的聚合检查点，验证阶段、版本、关系模式和状态哈希，然后严格加载模型。客户端本地共享检查点和旧 Gefra 几何检查点不能直接进入 C。

目标域按自己的连续／类别特征模式建立新的节点、可选边适配器和任务头。全部预训练专家及组合器**原参数**冻结。源预测器、RWSE 预测位置投影、EMA 分支、服务器探针和源私有适配器均不进入下游。

冻结不等于对整个共享前向使用 `no_grad`。梯度需要穿过冻结结构，才能更新输入适配器、Prompt 或低秩增量。共享模型保持评估模式，固定随机丢弃等行为。

### 7.2 四种模式分别改变哪里

| 模式 | 新增参数与位置 | 为什么采用 | 需要准确表述的边界 |
|---|---|---|---|
| `none` | 不新增三种适应模块；仍训练目标输入适配器和任务头 | 最基本的冻结基座迁移对照 | 不是严格的“仅训练线性头”探针 |
| `lora` | 原组合器 Q、K 加低秩更新 | 少量参数直接调整决定交互的内容映射 | 用官方 LoRA 类；关系映射、V、输出映射与原 Q／K 都冻结 |
| `adapter` | 组合输出后一个瓶颈残差模块 | 检验调整输出表达空间是否已经足够 | 只借鉴 AdapterGNN 机制；不含其逐层双分支、BN 和门控 |
| `prompt` | 所有节点、所有专家输出共同加一个 d 维向量，再进组合器 | 以很小预算改变组合输入 | 改写 GPF 加性机制；没有新增图节点／查询 token，不是仅改 Q |

三种额外适配是独立对照，当前不同时叠加。

LoRA：

$$
W_Q'=W_Q+\frac{s}{r}B_QA_Q,\qquad
W_K'=W_K+\frac{s}{r}B_KA_K.

$$
默认 r=4、s=`lora_alpha`=4。官方 `loralib.Linear` 原样保存在运行依赖目录；替换层时复制原权重、冻结偏置，设置 `merge_weights=False`，训练／评估切换不会把增量写回原权重。初始化低秩增量为零。没有 Q／K 层的线性门控不支持该模式。

残差适配器：

$$
\widetilde z=z+W_{up}\operatorname{ReLU}(W_{down}z+b_{down})+b_{up}.
$$
默认瓶颈 8，升维权重与偏置初始为零。它调整组合结果，本身没有直接改写组合器的路由。

组合输入提示：

$$
\widetilde H_{v,m}=H_{v,m}+p,\qquad z=C(\widetilde H,R),\qquad p\in\mathbb R^d.
$$
p 初始为零，在节点和专家之间共享，影响冻结的 Q、K、V 映射输入。它不是一个专家一个提示，也没有提示边。固定完整视图内，这种共享加法及后续计算保留节点置换等变性；有界采样按索引截断的过程不保证相同重编号下取到同一子图。

四种模式先按同一种子初始化公共输入适配器和任务头，再初始化特定模块，减少因构造顺序不同造成的比较偏差。当前图合成任务 F=5、d=64、单输出、无边属性、本地分支关闭时：公共参数 449，LoRA 额外 1,024，Adapter 额外 1,096，Prompt 额外 64。参数预算不同，公平比较还需预算控制。

### 7.3 可选目标本地分支与任务读出

默认 α=0，仅使用共享分支。可以从头建立目标域本地图编码器，逐节点融合：

$$
z_{final}=\alpha z_{local}+(1-\alpha)\widetilde z_{shared}.
$$
两个分支使用同一个新目标输入适配器。固定 α=1 时跳过共享前向，闲置适应参数不计入优化；可学习 α 用 sigmoid 参数化，要求初始化位于 (0,1)。该分支不是从源客户端加载的私有网络。

α 可以帮助检查性能是否依赖共享基座，但不是共享知识的因果贡献百分比。先用 α=0 比较不同预训练／聚合基座，可以减少从头本地学习掩盖迁移收益的风险。

节点分类取中心节点的默认 2 跳、最多 128 节点邻域，读出重编号后的根节点。超限按稳定索引选择，不同于预训练随机截断。图分类使用完整图的节点组合表示做均值池化后分类；超过上限会明确报错，不把整图标签隐式贴到随机子图上。代码逐视图计算，再拼接 logits 形成训练批次，图之间没有跨图注意力。

### 7.4 标签、划分和模型选择

任务支持多类、二分类和多标签分类。多类用交叉熵，二分类／多标签用仅在已观测标签上计算的 BCEWithLogits；缺失值要求 NaN，类别标签必须按协议转换成合法索引或 0／1／NaN。

每个 epoch 只训练训练样本，然后计算验证损失；选最低验证损失的模型，平局保留较早 epoch。恢复选中状态后核对全部原共享参数哈希未变，再做一次最终测试。当前不是按验证 ROC-AUC 选模型。

多类报告准确率，二分类／多标签报告 ROC-AUC 和非插值 AP，并对并列分数分组。当前 ROC-AUC 与 AP 都仅统计同时有正负样本的任务；无有效任务记 null 并报告有效数量。AP 不应笼统写成所有定义下都相同的 PR 曲线梯形面积。

同图节点协议可声明 `transductive`，允许完整结构与特征进入邻域，但仅训练根节点标签更新；图任务必须 `split_graphs`，整图与根节点 ID 不能跨划分重复。加载器会预先读取并校验所有划分，包括测试标签；测试标签不用于梯度与选模，不能表述为“训练前从未加载测试数据”。程序检查声明的 ID，不能识别改名后的重复图，也不能证明组合留出成立。

## 8. 预训练与微调的完整实验流程

### 8.1 正式数据需要先完成的外部准备

先冻结源图客户端划分、目标训练／验证／测试划分、组合因素定义和组合留出条件；导出张量字典与两个不同 schema 的清单。源清单声明客户端 ID、特征模式和允许源图路径；目标清单声明任务、输出维度、可见范围和各划分图／根节点索引。

源张量最基本包含 `x`、`edge_index`，可选 `edge_attr`、`original_node_id`；目标还需要 `graph_id`、`y`。源加载器有意不把 y、掩码、因素标签和预计算 PE 送入编码分支。

**程序不会自动下载／转换 PCBA–HIV，也不会依据因素标签自动过滤禁用源组合。** 无监督不使用 y，不等于读取目标测试图也是允许的；源图可见性仍必须由实验协议事先限定。源清单解决“读哪些文件”的接口，不能代替数据集内容审计。

### 8.2 联邦预训练每轮的实际顺序

```text
初始化一个共享专家＋组合器基座
为每个客户端建立私有适配器、预测器和 EMA 副本

for communication_round:
    所有客户端接收相同共享状态
    各客户端重置参考编码分支，保留私有适配器与预测器
    各客户端：局部采样 → 遮边／遮特征 → 节点潜表示预测 → AdamW／EMA
    各客户端上传 experts.* 和完整 composer.*
    服务器：固定平均，或生成探针、缓存参考、优化聚合权重
    保存本轮客户端上传、服务器基座、报告及实际探针
    本轮聚合基座进入下一轮下发

最终服务器基座 → 目标域本地适配
训练划分更新 → 验证损失选模 → 原基座哈希检查 → 最终测试
```

联邦轮数与服务器校准步数不同；本地 epoch、每图视图次数、可选本地步数上限又是不同预算。默认合成流程为两客户端、两轮、每轮每客户端三步本地训练，不是正式预训练预算。

### 8.3 入口与可运行命令

在项目根目录执行，每次使用新输出目录。下面只进行合成接口检查。

```powershell
# 只运行 A：获得各客户端共享检查点，尚无聚合基座。
python pretrain_fedg2c.py --use-new-design --smoke --max-steps 3 --output runs/local_demo

# 运行 A＋B：两轮共享模型下发／上传，服务器每轮做响应校准。
python pretrain_federated_fedg2c.py --smoke --server-config config/fedg2c_server_response.json --aggregation response --rounds 2 --local-steps 3 --output runs/federated_demo

# 运行 C：加载第二轮服务器检查点；选择一种独立适配方式。
python finetune_fedg2c.py --use-new-design --checkpoint runs/federated_demo/round_001/server/shared_backbone.pt --smoke --smoke-level graph --adaptation lora --epochs 2 --output runs/target_demo
```

正式 A＋B 运行把 `--smoke` 换为 `--source-manifest <源清单>`，并显式设置 `--config config/fedg2c_edge_prediction.json`；C 把 `--smoke` 换为 `--target-manifest <目标清单>`。设备可显式设为 `--device cuda:0`，本次没有验证 GPU。

`aggregate_fedg2c.py` 可对 A 的多个本地共享检查点单独执行 B，要求架构、关系模式、源协议、通信轮次及共同初始化相容；它不替代反复下发的新联邦入口。

**重要入口事实：** `pretrain_fedg2c.py` 和 `finetune_fedg2c.py` 默认不传 `--use-new-design` 就进入 Gefra。新预训练开关下，默认 `edge_prediction`；`legacy_pool` 是保留历史对照。既有 `scripts/common.sh` 仍调用 `pretrain_gefra.py`／`finetune_gefra.py`，所以直接运行旧 end_to_end 脚本不会自动启动 FedG2C 新方法。

### 8.4 要检查的产物

| 产物 | 用途与边界 |
|---|---|
| 每轮各 `client_*/shared_backbone.pt` | 本地上传共享状态；并非 C 所需的服务器聚合格式 |
| 每轮 `server/shared_backbone.pt` | 可进入下一轮或 C 的聚合基座；含架构、阶段、协议、轮次及状态哈希 |
| `aggregation_report.json`、`server_probes.pt` | 权重、校准／诊断 before／after、参考响应幅度及实际探针 |
| 客户端 `metrics.json` | 有限损失、梯度、遮蔽量、视图大小及参考标准差 |
| `communication.json` | 共享张量有效载荷，不是实际网络流量计量 |
| 私有训练状态文件 | 仿真中各客户端的本地权重快照；不传入服务器，缺少优化器／RNG 状态 |
| C 的 `target_model.pt`、`metrics.json`、`run_metadata.json` | 验证选中完整目标模型、一次最终测试及基座来源；不是仅含少量适配增量的发布文件 |

当前权重快照不支持精确断点续训；清单文本哈希也不等于逐个数据张量内容哈希。正式复现还需要完整数据身份和运行预算记录。

| [I-JEPA，CVPR 2023](https://openaccess.thecvf.com/content/CVPR2023/html/Assran_Self-Supervised_Learning_From_Images_With_a_Joint-Embedding_Predictive_Architecture_CVPR_2023_paper.html) | 完整参考分支、停止梯度、EMA、潜表示 LayerNorm 与 SmoothL1；`NodewisePredictionModel` | 为无需标签、无需统一原始特征重构目标的预测任务提供成熟机制 | 独立 PyTorch 实现；改为图遮边／遮特征、逐节点 GraphSAGE 预测、固定动量。没有复制图像模型与完整训练系统 |
| [BGRL，ICLR 2022](https://github.com/nerdslab/bgrl) | `DropEdges`、`DropFeatures`；`mask_edges`、`sample_feature_keep` | 图自监督中的已有结构／特征扰动，降低完全可见输入捷径 | 机制适配；新增无向成组删除、局部生成器、类别嵌入后遮蔽。没有照搬其双向增强视图训练目标 |
| [GraphGPS，NeurIPS 2022](https://github.com/rampasek/GraphGPS) | `get_rw_landing_probs` → `random_walk_encoding` | 为节点潜表示预测提供可见结构位置描述 | 迁移返回概率计算，改为有界无权图的稠密实现；没有移植整套 GPS 架构 |
| [GraphSAGE，NeurIPS 2017](https://papers.nips.cc/paper/6703-inductive-representation-learning-on-large-graphs) | 原 Gefra `mysage` 专家及 PyG `SAGEConv` 预测器 | 用邻域聚合建模局部图，含根节点路径便于处理遮边后的孤立节点 | 专家复用自有实现，预测器直接调用库；用它预测 EMA 潜表示是本项目适配 |
| [Attention as a Hypernetwork，ICLR 2025](https://proceedings.iclr.cc/paper_files/paper/2025/hash/abfa542f546df3c6c35695ec8d5bf4b9-Abstract-Conference.html) | 头轴 RMS 与两次收缩核心 → `composer.py` | 提供比简单加权更丰富的输入条件非线性组合 | 对官方 JAX 核心做 PyTorch 迁移；节点×专家布局、图关系偏置、残差与节点内专家平均是新增适配 |
| [FED-PUB，ICML 2023](https://proceedings.mlr.press/v202/baek23a.html) | 随机分块图＋标准高斯特征测试功能 → `sample_probe_bank` | 服务器不访问真实图时，仍可有统一代理输入 | 机制参考；改用小型 PyG SBM，在服务器运行上传模型。没有功能嵌入上传、相似度个性化或稀疏掩码训练 |
| [FedLAW，ICML 2023](https://proceedings.mlr.press/v202/li23s.html) | softmax 客户端权重、可微参数组合 → `mix_parameters/objective` | 让权重由功能目标校准，超越固定平均 | 机制参考；用 `functional_call` 和无标签读数／响应目标；不使用其监督交叉熵，也不学习整体缩放 |
| [GAD，ICML 2026](https://proceedings.mlr.press/v306/huang26bj.html) | 归一化扰动、固定参考、有限差分响应 | 基准输出匹配可能不保留局部敏感性 | 机制参考；把扩散噪声前向差分改为关系门控中心差分；没有生成／扩散模型，也不是几何专家恢复 |
| [LoRA，ICLR 2022](https://github.com/microsoft/LoRA) | 官方 `loralib.Linear` → 原组合器 Q／K | 小参数预算直接适配内容交互映射 | 官方类原样作为运行依赖；新增安装位置、复制原参数及禁止合并设置 |
| [AdapterGNN，AAAI 2024](https://github.com/Lucius-lsr/AdapterGNN) | 降维→ReLU→升维、零升维初始化 → `ResidualAdapter` | 检查只调整组合输出是否足够 | 独立简化实现；单个组合输出适配器，没有原论文逐层双分支、BN、门控 |
| [GPF，NeurIPS 2023](https://proceedings.neurips.cc/paper_files/paper/2023/hash/a4a1ee071ce0fe63b83bce507c9dc4d7-Abstract-Conference.html) | `SimplePrompt.add` 的共享加性向量 → `TargetModel.prompt` | 提供很小参数预算的组合输入适应对照 | 机制适配；移到专家输出处并零初始化；没有 GPF-plus 多提示注意力 |

还有三类要区别对待：GraphMAE 是 `graph_predictor.py` 注释中“浅层图解码器”的相关动机，当前没有直接移植其特征重构训练；MaskGAE 用于说明遮边与结构重构的相关背景，当前没有引入其边重构算法；FedDF 是服务器无标签代理输入融合的相关工作，当前没有引入其分类 logits 蒸馏训练系统。

Graph-JEPA 只出现在归档设计的历史依据中，当前主说明明确不再把它作为现实现依据。当前也没有导入 FedBook、FedGFM+ 的 VQ／代码本、AncDAI、AdaDPP 或源目录其他 baseline 管线；不能因为出身于 baselines-merged 就说这些算法都被融合进 FedG2C。

公开代码快照均有固定提交与 SHA-256 来源清单。A 的参考清单、B 的参考清单和 C 的参考清单共 25 个带哈希文件，本次逐个核验相符；超网络核心另外对照了官方固定提交的两次收缩源码。快照完整性证明来源可追溯，不证明整个方法等价复现。第三方快照的授权与运行依赖也不同：只有官方 LoRA 包被直接导入运行，新模型未导入其余第三方训练框架。

## 10. 本次运行验证到底证明了什么

当前环境为 Python 3.12.7、PyTorch 2.10.0+cpu、PyG 2.8.0.post1，CPU 单线程，CUDA 不可用。与旧说明中的历史环境版本不同，以下以本次实际环境为准。没有安装新依赖、下载真实图数据或运行旧几何路径。

| 检查 | 本次结果 | 可支持的结论 |
|---|---|---|
| A＋B 联邦流程 | 2 客户端×2 轮×每轮 3 步，共 12 步本地更新；各轮客户端与服务器检查点及探针完整 | 本地更新、共享上传、服务器校准、下一轮下发已连接 |
| 单独 B 的固定平均／仅输出匹配 | 两个入口进程均退出 0，产物可读 | 两种对照可以从相同本地上传运行 |
| C 的图分类／节点分类×4 模式 | 8 个入口进程均退出 0；均保存选中目标检查点 | 当前合成任务上的四种目标训练路径可运行 |
| C 冻结与重载 | 8 个原共享基座哈希均未变；同一线程配置重载后测试指标逐字段完全一致 | 权重冻结与完整目标检查点重载边界成立 |
| 第三方来源 | 25 个清单哈希全部相符；超网络两次收缩对照相符 | 所引用快照及核心机制有可追溯源码 |

重载核验最初使用默认 CPU 线程数，有一个损失与原报告相差约 6×10⁻⁸；统一为训练使用的单线程后，8 个目标任务均逐字段相同。此处是执行配置导致的浮点差异，没有改动模型代码。

第二轮响应聚合权重为约 (0.72744,0.27256)。以下每个“前→后”都是**同一轮上传、同一探针上固定均匀平均基准到校准候选**的比较，而不是跨轮训练收益。

| 轮次 | 校准输出 MSE：前→后 | 校准响应 MSE：前→后 | 独立诊断输出 MSE：前→后 | 独立诊断响应 MSE：前→后 |

第一轮的校准响应与独立输出误差增大，第二轮四项均下降。这说明“关系响应保持”是目标，不能把总目标优化理解成各项必然改善。第二轮的客户端 2 响应误差仍有增加，固定参考的折中也不能保证每个客户端受益。

## 12. 当前说明与代码中容易误读的地方

1. `README.md` 仍介绍 Gefra；理解新设计应读 `README_FedG2C.md` 及三份现行模块说明。
2. 总览与模块文档有一些链接仍指向旧文件名，实际现行文件是根目录的 `01_联邦预训练_本地关系条件专家组合学习.md`、`02_联邦预训练_服务器合成探针与响应保持.md`、`03_本地微调_冻结原始共享基座学习少量适应参数.md`。本次未改写原文。
3. `model.py::LocalPredictionModel`、`fedg2c/client.py` 及 `docs/archive/` 属于保留区域池化路径；当前默认对象是 `NodewisePredictionModel` 和 `EdgePredictionClient`。
4. 新流程没有原曲率专家、GW 聚合、Top-K 门控、VQ 代码本或 Riemannian Prompt Readout；这些文件存在不代表新前向会运行它们。
5. 预训练当前没有因素解耦监督、多样性正则或组合泛化保证；专家语义解释需要独立证据。
6. 服务器的响应针对关系偏置门控，探针无边属性、非真实分子；它不足以代表全部消息传递或真实图编辑响应。
7. `none` 仍训练输入适配器；三种适应模块参数数目不同。当前 C 按验证损失选模，没有自动 few-shot 支持集采样，也没有新链路任务入口。
8. 当前分享目录原本清除了测试与运行资料；`docs/review_artifacts_20261010/` 是本次阅读审计新生成的合成产物，不能误当成分享前已有的正式实验。

可以这样介绍当前方法，而不提前声称实验有效：

> FedG2C 面向联邦图预训练中的结构组合迁移问题，在统一隐藏空间内建立多个欧式图专家，并用图关系条件的超网络组合器形成逐节点表示。本地训练借助受扰动图与完整局部图之间的动量潜表示预测，同时学习专家和组合规则。服务器在无需真实客户端图的合成探针上，匹配上传模型的基准读数及关系门控有限差分响应，据此学习共享参数的客户端凸组合权重。下游冻结聚合专家与完整组合器，使用目标输入适配器、任务头和一种少量参数适应方式完成节点或图分类。当前贡献候选在于这套关系条件组合与响应校准的联邦连接设计；其真实组合泛化价值需要通过源组合留出、聚合消融和多任务迁移实验建立。
